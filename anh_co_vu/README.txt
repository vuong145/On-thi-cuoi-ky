# 📁 THƯ MỤC ẢNH CỔ VŨ (anh_co_vu)

Đặt các file ảnh (.png .jpg .jpeg .gif .webp .bmp) vào thư mục này.

Mỗi khi trả lời ĐÚNG 5 câu liên tục, web sẽ hiện ngẫu nhiên 1 ảnh từ thư mục này
ở cột bên phải để cổ vũ.

## 📤 Để mọi người xem được trên Streamlit Cloud

1. Bỏ ảnh vào thư mục này (đặt tên không dấu, VD: anh1.png, co_vu.jpg).
2. Commit và push lên GitHub:
       git add anh_co_vu
       git commit -m "Thêm ảnh cổ vũ"
       git push origin main
3. Đợi Streamlit Cloud tự redeploy (1-2 phút), hoặc vào share.streamlit.io
   bấm Manage app -> Reboot.

⚠️ Ghi chú: chỉ bỏ ảnh ở máy local thì Streamlit Cloud KHÔNG có ảnh.
Ảnh phải nằm trong repo GitHub thì mọi người mới thấy được.
